# Khamim Portfolio — Renaissance Gallery on Putty Paper

Portfolio pribadi [Khamim Zarkasyi](https://github.com/khamimzarr) — warm putty `#c4c3b6`, ink `#000000`, Davinci 374px wordmark, flat, no shadow.

> **Branch aktif:** `rollback-design` (design lama Renaissance) — LIVE
> **Branch cadangan:** `main` (design baru Slate & Lime) — tersimpan

**Live:** https://khamimzar.my.id (canonical) — alt https://khamim-portfolio.vercel.app — lihat [CATATAN-DOMAIN-GSC.md](./CATATAN-DOMAIN-GSC.md)

## Stack
- Next.js 16 (App Router) + Tailwind 4
- Playfair Display (Davinci) + Inter (Helvetica Now)
- Vercel — project `khamim-portfolio` (team `voiddarkfire`)

## Rollback
Design lama bisa diaktifkan dengan:
```bash
~/backup-khamim-portfolio/20261016-094907/rollback-design.sh soft  # branch baru (aman)
~/backup-khamim-portfolio/20261016-094907/rollback-design.sh hard  # reset main
```
